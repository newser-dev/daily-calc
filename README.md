# 간편계산소

한국어 생활 계산기 모음 정적 사이트 (애드센스 수익화용).

도구: 글자수 세기 / 연봉 실수령액 / 퍼센트 / 만나이 / D-day

## 배포 & 애드센스 절차

1. **도메인 구매 (필수)** — 애드센스는 `*.github.io`, `*.netlify.app` 같은 공유 서브도메인을 사이트로 등록할 수 없음. 가비아/클라우드플레어에서 `.com`/`.co.kr` 도메인 구매 (연 1~2만원).
2. **배포** — GitHub Pages(커스텀 도메인 연결) 또는 Cloudflare Pages 추천. 정적 파일이라 그대로 업로드하면 끝.
3. **도메인 반영** — `robots.txt`, `sitemap.xml`의 `YOUR-DOMAIN.com`을 실제 도메인으로 치환.
4. **서치콘솔 등록** — Google Search Console에 사이트 등록 + sitemap.xml 제출. 네이버 서치어드바이저도 등록 (한국 트래픽은 네이버 유입이 큼).
5. **애드센스 신청** — adsense.google.com에서 사이트 추가 → 안내되는 `<script>` 코드를 각 페이지 `<head>`의 주석 자리에 붙여넣기 → 루트에 `ads.txt` 업로드 (애드센스가 내용 제공).
6. **승인 후** — 광고 단위 생성해서 `.ad-slot` div 자리에 코드 교체.

승인 팁: 신청 전에 콘텐츠성 페이지(계산기 사용법, 관련 정보 글) 4~5개를 더 추가하면 승인 확률이 크게 올라감. 신청~승인은 보통 2일~2주.
